# 🧰 Ulogi - 你的生活效率工具箱

> **记录、同步、管理，一切尽在掌控。**  
> 从命令行到日常笔记，Ulogi 让效率触手可及。

---

## 📌 项目简介

**Ulogi** 是一个基于 Electron 和 React 的跨平台桌面应用，致力于成为你日常生活和工作的全能助手。  
无论是开发操作、学习笔记还是日常管理，Ulogi 都能帮你高效记录与同步，简化重复劳动，提升专注力。

---

## 🛠 技术实现

- **Electron + React**：构建现代、可扩展的桌面应用
- **Redux + TypeScript**：模块化状态管理，便于功能拆分与维护
- **自建 SOCKS Server**：网络辅助模块，为扩展功能做准备
- **可视化界面设计**：更符合用户操作习惯

---

## 🔍 项目背景

传统的移动端工具如书签、便签、笔记应用，大多局限于本地存储，缺乏同步能力，且无法跨平台高效使用。这些限制催生了本项目的开发。

Ulogi 最初源自一个基于 React Native 的项目（`fb-note-rn`），但 RN 在桌面端适配困难，开发成本高。为实现更自由的扩展与体验，项目最终转向 Electron + React 重新构建，打造真正意义上的**跨平台生活工具集**。

## 🔮 功能规划

Ulogi 不只是一个记录工具，更是你掌控信息、效率提升的中心。未来我们计划增加以下模块：

### ✅ 系统工具集

- 可视化系统操作（如 Git、Docker、SSH 等）

### 🧠 学习辅助

- 英语单词本、学习卡片

### 📓 日常记录

- 通用便签 / Markdown 支持
- 任务管理、计划安排


### 🧩 多工具整合（重点）

Ulogi 致力于打造一个内容整合与轻度编辑平台，包括：

- 🧠 **思维导图工具**：记录灵感，结构化思维
- 🎬 **本地视频播放器**：支持进度记录、播放历史管理
- 📸 **视频截图 + 截图管理**：
  - 支持快速视频截图
  - 多图拼接（如笔记图集）
  - 批注与合并管理
- 📁 **内容归档系统**：将思维导图、截图、笔记、资源文件整合管理
- 🧩 插件机制（预留）：用户可安装/开发扩展功能

## 🗂 本地配置：`app-settings.json`

- **位置**：`electron/support/app-settings.json`。
- **用途**：存储运行时的本地设置（目前仅 `settingsDir`，用于指定用户数据/写入目录）。
- **优先级**：环境变量 `SETTINGS_DIR` > `electron/support/app-settings.json` 的 `settingsDir` 字段 > 应用内置默认（`support/writing` 目录）。
- **注意事项**：
  - 请勿在 `settingsDir` 中设置为项目根目录（除非你明确要使用 `support` 目录），应用在 UI 和主进程上会阻止将项目根作为存储目录。
  - 该文件是纯 JSON；如果需要临时记录注释，请在仓库中使用伴随的 `electron/support/README.md` 或 `.example` 文件，而不要在 `app-settings.json` 中放置非标准注释，避免解析错误。

更多说明请参阅：`electron/support/README.md`
